# Kill the KING 
## Présentation du projet 
Kill the KING  est un jeu de cartes développé en JavaScript dans lequel le joueur affronte un ordinateur à travers 12 manches.
Le but est de remporter le maximum de points en utilisant intelligemment les trois types de cartes : Empereur, Citoyen et Esclave.

## Régle de jeu 
 Le jeu contient trois types de cartes :

 Empereur bat Citoyen.

 Citoyen bat Esclave.

 Esclave bat Empereur.

 ## Fonctionnalités
 Création de profils avec pseudo et avatar.

Modification et suppression des profils.

Sauvegarde des profils dans LocalStorage.

Système de jeu contre l'ordinateur.

Gestion des 12 manches.

Calcul automatique des scores.

Historique des parties.

Recherche et filtrage des parties.

Sauvegarde des données dans LocalStorage.

## Les outils utilisées
HTML5
JAVASCRIPT 
TAILWIND CSS
LOCALSTORAGE
GIT and GITHUB

## Gestion des données
Les données sont enregistrées dans le navigateur grâce à LocalStorage :

player : stocke les profils des joueurs.

historique : stocke les parties jouées.

account : stocke le profile sélectionné par le joueur.

Les données restent disponibles après l'actualisation de la page, sur le même navigateur.
